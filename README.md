# Lutan Trading Academy

GitHub-ready static recreation inspired by the publicly visible Tania Trading Academy pages.

## Files
- `index.html` — main academy page
- `vip.html` — VIP page
- `assets/style.css` — responsive styling
- `assets/app.js` — smooth scrolling

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `vip.html`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save. GitHub will provide the live address.

Replace the email address and any buttons/links with your own business links before publishing.

### Important
This is a self-contained recreation, not the original site's source code or proprietary backend/assets. Trading claims and performance figures from the reference site have intentionally not been presented as verified facts; examples on this version are framed as educational examples.
